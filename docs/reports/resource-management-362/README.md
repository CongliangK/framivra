## 已验证交互

- 初始显示项目 296 B、cache 85 B、out 23 B、其他 188 B，配置档位 core、跳过链接 0。这里是合成夹具的逻辑字节，不是实际视频项目的空间占比。
- [清理预演](<cleanup-preview.png>)列出唯一 27 B 合成候选；原生快照确认勾选框未选、确认按钮禁用，且文件仍存在。仅在显式确认停写后执行，UI 报告回收 1 项 / 27 B；刷新为项目 269 B、cache 58 B，文件系统确认候选消失，时间线、原件、作者 SVG 与输出字节保留。截图处于侧栏滚动位置；确认按钮在更下方，不把截图裁切误称按钮不存在。
- 手工编辑区域仍可展开并通过侧栏内部滚动访问，未授予编辑许可。[390×844 窄屏](<mobile.png>)的页面 scroll/client 宽均为 390，dialog 均为 372，没有横向溢出。
- [最终配置界面](<cache-settings.png>)读取 core，并提供 off/core/aggressive 三项。通过原生审核、勾选和确认分别保存 off、aggressive、再恢复 core，并读取隔离配置核对实际持久化，这组三次 CAS 操作在先前 `b8fdc84` 侧栏包上完成；最终包只补验设置读取与选项，变更差异仅监视器 wrapper 布局，不把两轮证据混为同一包。
- 完整同机侧栏基线 492 项：454 PASS / 10 FAIL / 28 SKIP；当前实现 513 项：474 PASS / 相同 10 FAIL / 29 SKIP。十项都受现有 macOS 语义写入仅 Linux 验证限制；未改门禁以刷绿。新增 opt-in 真实宿主测试另行通过，详见 PR。
