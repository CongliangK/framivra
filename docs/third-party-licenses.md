# 第三方许可与模型下载边界

## 唯一证据清单

资产、来源、许可声明、限制、未知项、默认载荷范围与固定官方证据文本/哈希的唯一 home 是 [model-license-inventory.json](model-license-inventory.json)。项目自身许可文本归 [LICENSE](../LICENSE)；清单仅引用其本地 home，不改变所有权或给上游资产重新授予许可。

`DECLARED` 是上游直接声明，不是法务签发；`RESTRICTED` 需要额外条款/用途审查；`UNKNOWN` 与 `UNVERIFIED_RUNTIME_VERSION` 不算合规通过。证据版本不代表本机已安装版本，更不代表已有镜像快照相同。代码许可不能代替权重、派生/量化资产、嵌套辅助权重、API 服务或输出权利；外部二进制以具体构建及其附带通知为准。

默认源码/内核载荷与可选安装下载、外部进程调用是不同边界。审计只确认声明的默认载荷和证据一致性，不宣布所有可选工具、服务、模型或第三方传递依赖均可商用。本清单不读取用户配置、私有权重或凭据，也不猜本机启用态。

## 零写态检查

```bash
env python3 scripts/model_license_policy.py audit
env python3 scripts/model_license_policy.py plan qwen-asr-1.7b
env python3 scripts/model_license_policy.py download --help
```

`audit` 显示既有改编源件的未知 provenance 警告；根许可证声明不能代替改编来源/notice 的权利核实。它检查根许可证声明、内核依赖载荷与已追踪的模型/二进制扩张，保什么：清单形态、保存的证据哈希与当前默认载荷边界；不保什么：法律效力、全部数据权利、隐藏/改名二进制、任意传递依赖或外部进程行为。新增默认组件或上游资产须独立复核，不靠扩展名检查取得许可。专用测试由统一 unittest 入口发现；文档七门不自动执行法律审查或真实模型下载。

## 下载与运行政策

未确认用途时按可能商业处理。旧初始化器的混合 `--download` / 未固定 `--install` 路线在任何配置探测、建环境、clone、pip 或权重请求前明确拒绝；已有用户文件不删、不覆盖，默认本地探测仍可运行。不得以泛泛的 accept 标志越过未知项、限制条款或镜像对应关系。

合法 opt-in 使用 `download --help` 所示的单资产接口：先读清单及完整固定官方文本，再逐资产确认证据哈希和用途。仅已明确声明许可、具有固定官方快照的受支持资产可走该接口；强制官方源与固定 revision，不采用环境中的镜像或认证令牌回退。下载是**写操作且可能很大**，不是上述零写态示例；本批验证仅使用 mock/临时小文件，不实际下载权重。目标目录必须不存在，下载暂存、通知核对成功后发布并保留来源/许可通知；保存的记录不是签名、法律授权或再分发许可证。

模型构造器可隐藏下载别的仓。IndexTTS worker 在读取资产、创建项目产物、导入/构造上游前拒绝未审查完整辅助链；主模型协议不能给辅助资产授权。现有资产保留，但存在不等于已确认权利；恢复该链需要补足具体证据并评审受控适配器，不能改一个状态或传 accept 标志绕过。

本门不 sandbox 用户自装的 BGM CLI、通用 ComfyUI 服务、浏览器安装器或任意外部脚本。其边界、未固定版本与未知权利在清单中显式列示；调用者须另行审查，不能把本门的默认载荷通过宣称成这些可选运行面的合规通过。不会为许可审查关停渲染内核，也不会执行真实模型/付费 API、发布、部署或凭据变更。

## 分发物核对

Git 源码归档/clone、setuptools sdist 与内核 wheel 是不同载荷；边界声明归清单的 `distribution_policy`。源码中的 vendored fpng/libspng 按本地原文和逐文件哈希登记，libspng 的内嵌 libpng 派生代码通知也必须保留。不会修改上游原文或把根 MIT 覆盖到第三方代码。

已知默认载荷阻塞在资产 `distribution_blocker` 中明列；占位媒体以无外部输入的黑色视频/静音重生成，Electron 自有源码由维护者明确确认权利并授权 MIT，证据归清单。外部 Electron/npm 依赖仍须独立审查。`audit` 的 `ok` 仅表示清单完整性检查成功，`known_payload_blockers_absent` 只表示已登记载荷阻塞为空；只要仍有来源警告，`release_eligible` 保持 false。该字段也不是法律放行。模型、代码、媒体/数据、字体和外部服务分别审查；固定下载版本也不能代替完整通知或传递依赖证据。

FR43 已知默认载荷硬阻塞已消除；三项可选模型实现的改编来源警告仍在清单中保留，不宣称其权利已证。首稳定支持范围是内核与公开 demo/CDP 路径，不涵盖这些可选模型实现。源码包含它们的实现及警告，不包含外部模型权重、Electron/CEF 等二进制，也不默认下载它们。来源未核实不等于已证明存在许可冲突；当前记录不据此授予任何上游权利。

`distribution_license_audit` 只读调用者提供的本地归档，不解压、不联网；输出归档 SHA-256、逐成员哈希、存在的已登记组件和适用阻塞。保什么：所检查字节的清单、已登记源码/通知完整性及已知权重扩展名检查；不保什么：未登记改名载荷、上游权利、法律兼容性、远端已发布包或外部安装环境。合法相对链接只记载目标，不跟随。真实发版须对每个最终资产单独留证，不能以本地候选构建代替。

```bash
env python3 -m scripts.distribution_license_audit --help
```
