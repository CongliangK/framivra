## 从成片提炼可复用方法

表中“模板方法”是独立实现方向，不表示已达到上游成片的所有材质、镜头或声音质量。字体列描述字形角色，不要求安装上游的特定字体。

| 上游目录 / 风格 | 实际源码观察 | 模板方法：叙事、构图、字体、运动与转场 |
|---|---|---|
| `05-cel-boil` 手绘逐帧 | Canvas `js/scene.js`；手绘字体预载；按时间调用 render | 从草图到定稿；纸色底配不规则线；手写角色字；按整数帧保持线稿、加预备与短 smear；用笔触覆盖带出下一信息。boil 必须按帧种子生成。 |
| `03-isometric` 等轴测 | 模块化 `js/main.js`；场景与运镜入口分离 | 从一个节点到系统；共同投影和深度排序；无衬线标签；底面、立面、顶面依次生长；沿网格平移串联，不用透视缩放冒充等轴测。 |
| `01-flat-vector` 扁平矢量 | 大型 Canvas 整页与共用 cue 表 | 一个基本形触发功能链；纯色、留白与单焦点；粗细无衬线层级；预备、冲出、回弹与错峰；主体形变或色块擦除承担转场。 |
| `02-line-art` 线条 | `film.js` 将路径长度、camera、holds、fill 和 wordmark 分开计算 | 一条线组织因果；负空间、等宽细线；克制衬线或细体；路径按长度生长并在语义节点停顿；上一轮廓延续为下一轮廓，最后线转面收束。 |
| `04-3d-render` 三维渲染 | HTML 加载 Blender 预渲帧，叠字与颗粒；并非浏览器凭空产生 PBR | 物体成为英雄，阵列服务主角；棚拍层次、材质对比与少量文字；长尾缓动与接触回弹；匹配轮廓切镜。程序阴影/渐变只属材质化近似，不能宣称完成 Blender PBR、景深或软体模拟。 |
| `08-morph` 形状变形 | Canvas 整页并引用字体轮廓数据 | 用轮廓解释事物关系；中央主形配短标签；中性字形；顶点对应、过渡中介形与轻微挤压；变形本身承接场景，不靠淡化遮跳变。 |
| `19-paperclip` 贴纸解释 | Canvas 整页、逐句 cue 与信息板组织 | 提问、分解、证据、结论；大画布贴纸与图表分区；数据无衬线字；按句揭示，镜头连接信息；数据必须来自可换内容，图标近似不可宣称照片抠图。 |
| `22-hud` HUD/FUI | holo、hud、post 模块；字体等待、扫描与时间函数组合 | 搜索、检测、确认；中心目标与外围低层级遥测；等宽数字；扫描、括号吸附、数值稳定；锁定事件改变层级，装饰数据不冒充实测。 |
| `06-collage` 拼贴剪纸 | Canvas 整页，照片剪影与纸张构图 | 用不可能拼装表达观点；纸块、错位比例与网点；杂志粗字加注记；量化帧时间与关节旋转；拍贴/翻纸转场。独立程序剪影需明确区别照片拼贴。 |
| `12-aurora-glass` 极光玻璃 | `main.js` 为独立入口，玻璃与光场共同编排 | 从光场聚焦到产品卡；邻近色、大留白、清晰信息前景；细无衬线；低频漂移、小幅位移；光场流动承接卡片切换，不把模糊当信息。 |
| `09-bauhaus` 几何包豪斯 | Canvas 分色版加 WebGL 印刷后处理；cue 事件映射 | 用秩序建立和重组表达结构；网格、基础形与限色；几何粗字；中心/边角轴旋转及整模数位移；模块重排成下一构图，机械节奏不用弹跳替代。 |
| `10-synthwave` 合成波/VHS | Canvas 整页、透视和媒介质感层 | 接近、穿越、抵达；地平线、透视网格与日轮；展示字与小号仪表字；景深层速度差；用地平线或光扫承接，噪声与跳帧由帧号确定。 |
| `20-pixel` 像素 | `film.js` 与像素字体预载，低分辨率画面组织 | 任务、行动、奖励；网格地形和有限色板；像素角色字；整数坐标、分步精灵、最近邻；卷轴或整块切换，避免平滑抗锯齿伪像素。 |
| `07-liquid` 液态 | WebGL engine、SDF 字形、scene/type 分层 | 一滴扩展为系统或字标；有机前沿与少量焦点；圆润主字；细颈拉伸、断裂回弹、延迟液滴；液体前沿成为遮罩。简化波形不是完整流体模拟。 |
| `18-hanazi` 综艺花字 | Canvas 整页、竖屏节目结构与 cue 表 | 铺垫、情绪、笑点、反应；人物区与字幕区；胖字多层描边；逐字错峰弹跳和符号反馈；按语义切换字幕，保护人物关键区域。 |

## 复用与验收边界

可换内容包括主题、标题、短句、标签、数据与配色；节奏应由帧窗口、错峰和强调点驱动，而不是将上游固定故事改名。每款需用另一组不同长度文案和不同数据验证布局及叙事，不能只改色。所有动效保持 Framivra 的整数帧确定性与 timeline 接口；通用机制见 [gfx 协议](skill/references/gfx.md)，不在此重复定义契约。

源码阅读与 DOM 检查只证明部分机制。真实输出还需渲染、抽帧、字体/遮挡检查、时间线/QC；独立艺术审查需另外评价叙事、构图、字体与节奏。上游 AI 评分不是本模板的验收成绩，单帧截图也不能证明整片完成。
