# BGM_SHORTLIST · 视频配乐选曲册（第二版：知名度×质量维度并入）

> v2 2026-08-26 产出：v1 只算了工程要素（密度/音域/反复/许可），被用户批评漏了**作品知名度与本身质量**。本轮对 81 件候选池（v1 全部 50 实体 + 知名度优先新增库内 26 + 库外心愿 10）实抓三源外部数据并合成评分。旧版与私有历史未随开源版发布。
> 面向中文视频 BGM 场景的历史派生选曲表。原始榜单响应与采集工具为内部材料，未随开源版发布；本册不承诺可从公开仓库完整复算。
> 用户先验不变（三轮试件沉淀）：**吉他拨弦 > 钢琴 > 鼓**；情绪象限**轻松/愉快/活泼**；口播床要中频让位/瞬态稀疏；暴露位可用旋律性强的大师名片。
> 许可纪律不变：PD/CC-BY/CC0 可投产（CC-BY 记署名义务）；**CC-BY-SA 一律不进投产清单**（804 件挂起，见 §七）。

**合成公式**（fame 与 quality 互相独立；eng 为 v1 工程判据的数值化）：

```
知名度 fame(0-10) = 0.45·F_bili + 0.30·F_cf + 0.25·F_zh
  F_bili = min(10, 10·log10(top3播放+1)/log10(300万))     # top3 合计 300 万=满分
  F_cf   = clip((301−CF名次)/30, 0, 10)                    # 取 2025/2026 有值名次较小者；双榜无=0
  F_zh   = zhwiki 条目有无（10/0）
  top3 采集缺失 → (0.30·F_cf+0.25·F_zh)/0.55 重归一，标 degraded

质量 quality（离散档，证据链降序，逐件 rationale 存 内部原始数据（未发布））：
  CF 名次≤100 → A+（听众年度票选，强证据）｜101-300 → A
  wiki_en≥30000B 或 sitelinks≥30 → B+ ｜ ≥8000B 或 ≥12 → B
  有 en 作品条目 → C+ ｜ 无条目 → C（仅音乐学编辑判断，pool note 字段注明依据）

工程 eng(0-10) = (密度分 + 反复分 + 时长分 + 许可分 + 格式分)×10/8
  密度 ≤4/s→3；4-8→2；8-12→1；>12→0.5 ｜ CLEAN +1；LY缺 −0.5
  时长 30-120s +1；120-300s +0.5 ｜ PD +1；CC0 +0.8；CC-BY +0.5；SA/库外 0
  库内 MIDI +2；库内 mxl（转换链缺口）+0.5；库外 0
  （实测= v1 附录 A mido 实读；EST=本轮听谱估计档，逐件标注于 score_fame.py ENG 表）

排序：曝光位价值 = fame×q_num（A+=5…C=2.5）；床乐位价值 = eng×(1+fame/20)
```

**坑警**：B 站搜索 numResults 封顶 1000（热门词均 1000，无区分度），区分信号以 top3 播放为准；空 result ≠ 无结果（风控假空，详见 §八）。

## 五、反差发现（数据说了什么）

- **A. 名气大但工程差（只配曝光位）**：Entertainer（eng 5.0：17.8/s 级密度+volta+253s）、命运/贝七（缩谱 10/s 上下+317-438s）、d 小调托卡塔（572s 管风琴）、Eine kleine（LY缺+320s）、丢失一分钱（391s）。**名曲的织体天然不适合口播床——v2 十佳分榜正是为此。**
- **B. 工程好但没人听（v1 一梯队主力实况）**：Knjže（top3=0）/Horetzky 邮号（1958）/Tambourin（3849）/Carulli GS（5406）/La Biondina（6072）/BWV999（8958）/Mertz（12071）/Carcassi（18709）/Coste（24354）。**它们仍是床乐弹药库（eng 7.5-10），但绝不能当"名片"卖**——v1 的问题正是把工程分当成了唯一排序。
- **C. 情绪反差**：月光/奥丝之死/Clair 名气第一梯队但情绪=忧郁/哀——与"轻松愉快"先验相反，价值在舒缓档与曝光位，不入活泼主推。
- **D. 平台认知结构差异**：勃拉姆斯摇篮曲 B 站 96 万播放（儿歌内容带火）vs zh 无条目+无 CF（fame 仅 4.16）；创意曲 24 万（琴童刚需）vs fame 3.74。**B 站实用内容流量 ≠ 作品名气**，三源合成正是为对冲这种单口径偏置。
- **E. 乔普林悖论**：Maple Leaf B 站 25 万/Entertainer 15 万（有真实听众），但 zh 无条目+CF（英国榜）无乔普林——fame 公式压到 3.75/6.10。判定：**B 站单口径第 9 名的曝光位实力**，综合分低估是口径代价，v2 在曝光位表备注。

1. **平台采集限制**：采集受平台风控限制，需自行合规获取；缺失数据显式降级，不冒充零。
