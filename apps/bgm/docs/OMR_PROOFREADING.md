# OMR 产线校对协议（OMR_PROOFREADING）

> 闲时任务三（《春》RV269）R3 轮沉淀的可复用方法论，2026-08-27 定稿。适用：Audiveris OMR 底稿 → 符号层校对 → 自研引擎改编的产线三段式（REGISTRY §11.2）。
> 逐件报告模板见 `out/spring_omr/PROOF.md`（首例）。

## 一、切条策略（图像准备）

1. **几何源=Audiveris 自身**：从 `.omr`（zip）内 `sheet#N/sheet#N.xml` 提取 `system/staff/lines/point`（谱表 y 坐标）与 `stack`（小节列 left/right），按 stack 逐小节切条——比行投影法稳（投影阈值对密集谱面失稳，首例实测页 3/4 系统间隙小于合并窗）。stack 数应=小节数（首例 83=83，交叉验证结构判据①）。
2. 渲染 ~200 DPI（校对够用；OMR 正式跑 400 DPI 是另一回事）。切条边距：上 -58/+42 px（200DPI 口径）——加线与力度记号要留足，首例首版 -45/+30 被审出加线贴边。
3. **盲读副本**：乱序条带（固定 seed，映射存 map.json）。谱面小节号保留（遮挡小节号会切掉高音加线——两害相权，对 OMR 锚定的隔离靠「校对代理不见 OMR 数据」承重，不靠遮挡）。

## 二、两遍独立盲转录

- **pass A**（顺序）+ **pass B**（乱序）：两个干净会话代理，只见图与读谱纪律，不见 OMR/MusicXML/曲库记忆；逐音计算式（谱号→线间→调号→临时记号），禁轮廓式整句读；装饰音/8va/休止/冲突单列字段；不确定音加 `?`。
- **顺序铁律：先两遍盲转录，后取 OMR 对拍**（防锚定）。
- 名曲先验风险必须写进任务书（「谱面印什么读什么，与记忆冲突时以谱面为准」）。

## 三、对拍与指标（关键经验：口径选择决定成败）

1. **自一致性**：pass A×pass B 逐 bar-voice 比对。首例实测：bar-voice 全等率仅 24/105、音头级 74%——**AI 读谱通道在密集琶音/震音/和弦内音上自身噪声显著**，<98% 门槛大面触发属常态，不必恐慌，进裁决。
2. **裁决**：分歧项交独立裁决代理（只见两份假设+图，仍不见 OMR），输出 final+follows+n_heads_visual。**必须分片**（每代理 ≤13 张图）且**边裁边写盘**——35 张图单代理裁决首例实锤断片无输出（视觉负载耗尽）。
3. **主线审计**：裁决输出不可全信（首例裁决代理在 4 个同纹理小节系统性少计一组二音和弦）。主线对代表性小节做 4-5 倍单谱表裁带亲数（审计两次同构条带互证后可推广到逐字相同的兄弟小节）。
4. **误差率口径（必须双报）**：
   - **多重集口径（门判定口径）**：同小节同声部音高集合比对（精确配对→残余按 pitch-class 配对=八度错→残余=漏/多）。e_raw=(八度+漏)/真值音头数；insertion=多/OMR 音头数。**理由：读谱层无 onset 信息，序列序=读取序而非音乐序**。
   - **序列口径（披露口径）**：文档序编辑距离（match=0/同音级异八度 0.4/异音 0.8/增删 0.5）。**和弦内音符次序在印刷读法（自上而下）与 MusicXML 导出（常自下而上）间无语义约束——纯换序会伪装成「八度错/增删」**。首例实测：序列 6.87% vs 多重集 3.70%，差值主体=12 处 E3/E4 型纯换序+平行六度段的 del/ins 对。
   - 多重集口径的盲区（口吃内换序不可见）如实披露。
5. **降级判据**（任务书口径不变）：多重集 e_raw>5% 或结构不可恢复 → 停在校对轮交付报告。

## 四、结构四判据（全机械化）

| 判据 | 操作 | 首例结果 |
|---|---|---|
| ① 系统-小节映射 | .omr stack 数=导出小节数；切条与小节一一对应 | 83=83 ✓ |
| ② 小节号连续性 | 导出 number 序列 vs 无重复无跳号 | 0-82 连续 ✓ |
| ③ 时值不变量 | 逐小节逐声部游标和=拍号（转换器自动算，游标旗披露）；不可修复小节>5% 触发 | 4/166≈2.4%，proof 范围内 2 处一次修正收口 ✓ |
| ④ 声部对齐 | 各 part 小节索引 1:1；休止占比>80%=幽灵红旗 | 1:1 ✓，无幽灵 |

## 五、转换层进闭环

- 对拍终点=转换器输出侧（`mxl2notes.py`→notes[]），converter bug 自动计入误差率——不是对 .mxl 原文对拍。
- 转换器必须处理：divisions 逐小节变化/多 voice backup/chord 同 onset/**tie 链合并**（谱面一个音头=一个逻辑音，对拍口径=音头数）/谱号变更记录/游标旗。
- 语义写死在 docstring，fixture 单测进 fast 档。

## 六、坑表（首例沉淀）

1. 多 PNG 文件参数=各自独立 book，先合多页 TIFF（REGISTRY §11.2.1 坑 2 同源）。
2. 跨乐章标题页触发 movement 切分覆盖导出（§11.2.1 坑 1）——切条也要按乐章页范围。
3. **行内谱号变更**（小节中段换谱号）人读两遍全漏、OMR 反而正确——裁决时「OMR 与两遍人读都不一致」不自动等于 OMR 错，用几何（该小节是否系统首）+裁带审计仲裁。
4. 裁决代理对同纹理小节有系统性偏差（少计和弦组）——审计发现后同案推广前必须两次独立同构审计互证。
5. 视觉模型数 15+ 音头的整条带不可靠（计数漂移 ±3）；单谱表 4-5 倍裁带+约束化提问（「逐组清点，格式：组N:[音名]」）才可用。
6. 低音谱号判定：谱号 glyph 与休止/低音图形在低分辨率易混——问「谱号是什么」前先确认该条带是否系统首（非系统首条带左缘无谱号）。
