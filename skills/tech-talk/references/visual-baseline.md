# visual-baseline · 色调与视觉宏观基准

> **来源**：工作区 `AGENTS.md` §五「视觉」现行规则（权威口径，D22/D37/D50）+ `assets/gfx-templates/_tokens.md` 设计基准。提炼日期：2026-10-03。
> **分工**：本文讲**宏观取向**（为什么、什么方向、判什么门）；**色彩具体值/字号梯度/组件模式以 `_tokens.md` 为准**，帧驱动协议以内核 `skill/references/gfx.md` 为准，本文不重复数值表。D 号溯源见工作区决策台账。

## 一、配色基准（D22）

- **禁深蓝/蓝紫渐变科技风**——蓝色像素占比应为 0（gfx 页自查项，违反=P1）。
- **白底 + 暖色（卡其/琥珀）+ 数据色**基线：暖白/纯白底、近黑主文字、琥珀做强调（点亮/曲线/下划线）、卡其做克制点缀。
- **功能色仅限数据语义**：红=删除/失败、绿=新增/成功，不作胜负装饰渲染。
- 取向理由：与「AI 科技感=蓝紫渐变」的泛滥模板反着走，形成频道辨识度；暖白底对真人 pip 叠加与字幕可读性友好。

## 二、背景板内容原则（D22）

- **背景板只放口播不念的东西**：口播会念的信息不上画面；可上的是图表数据、演示、图形、链接。
- **大标题+文字列表画面禁用**——gfx 以**图表数据型 + 演示型**为主；导航文字 ≤6 字。
- 文字量「一眼读完不念」；桌面演示画面保持真实系统外观（模拟 UI 用真实系统配色）。
- **「口播没念的数据」积极上屏**（用户拍板）：后端清单/阈值表/官方指标等数据卡是加分项——与「不念口播稿」不矛盾：不念≠不上，念的≠上。

## 三、pip 悬浮窗规范（D37 收编红线）

- pip=**1:1 方形 420px、右下角、边距 60px、脸部中心裁切**（用户拍板「左右留背景没必要」）。
- **pip 安全区红线**：pip 在位期间（约 x≥1440 ∧ y≥600 区域），gfx 页关键内容禁入该区——受保护元素须整体满足「右界 <1440 或底界 <600」之一；设计期就按约束布局，事后返工=整版重排+全量重渲。验收门=终态帧安全区像素扫描（与底色差 >45 判墨迹）；装饰辉光可豁免须留裁定记录。
- 字幕最长行宽度 vs pip 几何要**程序化预检**（实测 20 字行 ≈1160px 居中，与方窗有 ≤120px 潜在重叠带）。
- gfx-full 页右上预留出镜小窗安全区 ~440×260（信息密集帧可短暂隐藏）。

## 四、gfx 页视觉硬规则

- **透明底页必须自带底色才自包含**——依赖「恰叠在下层画面上」的透明页，剪掉下垫即落黑场。新页设计先问：它下面最坏情况是什么？
- **全屏 clip 禁 alpha fade**（首帧 alpha=0 露黑场画布=黑闪）；全画面切换只用硬切，fade 只给「下层有画面」的叠层用。
- 下方信息卡几何带：y∈[590,860]（脸下方），860 以下是字幕烧录区；键帽/字幕带/pip 位置变更必须做**全局层间碰撞扫描**（两个子系统各自合规、叠加后打架是 v3.7 七项布局病灶的根源）。
- overlay 卡避让几何：上带卡=投影尾预算（墨迹下界 < 脸带顶）；下带卡=卡底+投影 < 字幕带保守线。

## 五、封面产线（D50，2026-09-13）

- 规格口径=**16:10（1920×1200）上传**；文字安全区=**水平 12%~88% / 垂直 10%~80%**（当日线上实测：电脑端全入口 16:9 裁上下各 5%、App 首页双列 ≈1.38:1 裁左右 ~7%）。
- 文案=大标题+小字仅两行；背景生图走 imgen **GPT 系模型**（用户拍板：兜底不用 nano）。
- 工具=`apps/cover/make_cover.py`（prep-bg/render/previews/qc 一条龙）；全知识与 QC 门 → 本包 `references/cover.md`，配方 → `references/runbook-r5r6r7.md` R7。
- 比例结论有平台时效，**跨季度复用前抽查一次线上现况**。

## 六、视觉判读证据原则（历轮五次应验）

- **视觉模型判读只作线索**：局部放大图会幻觉组构（把琥珀虚线读成徽章）、空壳条带会幻觉出内容、OCR 数字误读率不低——**DOM dump / 帧缓存像素 / α 合成比对三件套才是权威**。
- 「合成法」（缓存帧 α 合成底图 vs 成片帧，mean diff 噪声级）可一次性钉死整页时间轴零偏移，是 gfx 层时间对位复核的标准武器。
- 小面积 gfx 的 qc 灰度探针有假阴性（内容覆盖 <10% 帧面被稀释到门下）——遇 gfx 窗口 ✗ 先跑**全分辨率 α 掩膜复核**再定性（G11）。
- gfx 交付自查三件：协议（同 f 同像素、无 animation/Date.now/Math.random）+ 风格（D22 禁则逐条过、蓝像素=0）+ 数据（画面数字与需求单口径逐字比对，溯源写 data-sources.md）。

## 七、与 `_tokens.md` 的关系

`assets/gfx-templates/_tokens.md` 是 **D22 的数值落地**（调色板 token / 字号梯度 / 组件模式 / 页面骨架），随首期全程验证。冲突裁决序：内核 gfx.md+源码 > _tokens.md > 需求单例外。本包 `references/voice-ime-paradigm.md` 另存编排层成熟范式速查（句锁节拍/曲线 KV-TP 等），三层各管一事：**本文管取向、_tokens 管数值、paradigm 管编排手法**。
