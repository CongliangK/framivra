# Framivra 工作台：产品范围

本说明仅约束 DSH 插件界面；用户入口见 [README](README.md)，安全与内核契约见 [开发文档](DEVELOPMENT.md)。

- **使用者与任务**：在自己的会话工作区浏览工程文件，查看合成画面、定位时间线，再按需编辑或把精确引用加入草稿。
- **已确认方向**：剪映 / Premiere 式图形工作台，不做文字报告页。左侧工程文件，中间预览，下方多轨时间线；属性与高级操作按需展开。窄侧栏可原位展开工作台，不丢失未保存状态。
- **信息优先级**：画面、播放头、真实片段范围优先；路径、完整版本、原文 JSON、协议限制与诊断保留在次级详情中。
- **视觉约束**：沿用宿主字体与主题；中性暗室预览画布、低层级分隔、4px 间距网格，控制文字 13–14px。视频蓝、图形紫、音频绿、字幕琥珀只表示轨道类型；红色播放头、清晰选区与焦点用于定位，不虚构缩略图或波形。
- **图标优先**：常用工具与切换采用已核验开源许可的统一图标，键盘/悬停可读名称；名称、帧号和关键授权/提交文案不隐藏。图标数据和完整第三方许可证随安装包离线交付。
- **交互底线**：标准按钮、文件列表、原生对话框；键盘可达，状态可读；路径核验只检查已保存配置，浏览只限当前工作区。预览缓存写入和时间线写入各自明确授权，不自动渲染、提交或发送。
- **验收范围**：真实官方 npm 宿主的宽屏及窄栏、空态 / 加载 / 失败 / 成功、文件夹导航、配置核验、固定帧预览和已有编辑安全回归。视觉布局不等同内核验证或成片 QC。
