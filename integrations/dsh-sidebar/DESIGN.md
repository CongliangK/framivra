# Framivra DSH 侧栏 · 工作台视觉设计约定（DESIGN.md）

范围：仅 `integrations/dsh-sidebar`（宿主内嵌 React 客户端）。目标气质：剪辑工具（CapCut/Premiere 式）——低持久文字、画面优先、密度紧凑、深色单色调。本文只记录已定决策，供后续修改对照。

## 意图

- 使用者：在 DSH 会话里核对/微调 vtx 时间线的视频作者，屏幕常驻侧栏，720p 笔记本也要可用。
- 核心动词：选时间线 → 定帧 → 看画面 → （可选）复制/入稿。其他一切让位。
- 感觉：像监视器+时间线的工具，不像设置页。深色、低噪、控件短促。

## 布局铁律（720p 基准）

- 未打开工程时不显示黑色 16:9 空播放器：宽屏保留 248px 文件区，主区用统一背景与限宽 480px 的紧凑引导。窄屏打开文件区时隐藏重复引导，关闭后恢复；已打开工程的布局不受此规则影响。
- 文件区固定标题、路径和筛选，只有 `.fv-file-scroll` 滚动；宽屏上半区网格必须能收缩且不超过父区高度。初始不自动浏览；「浏览工作区」显式展开并聚焦筛选，重复点击不重读目录；路径入口复用顶栏表单。
- 展开态对话框：94dvh；内部每个区域只允许**一个**滚动宿主，禁止三层嵌套滚动（`.fv-body` 展开时应 `overflow:hidden`，滚动只属于文件列表、monitor 内容、时间线 lanes、inspector 各自区域）。
- 监视器（`.fv-monitor`）：帧定位/步进行 `position:sticky` 固定；展开宽屏时画面舞台填满监视器剩余空间，以 `object-fit:contain` 显示真实已验证 PNG，不再限制为 `20dvh`。次级操作收进有高度上限的 `<details>`，不挤走画面。
- 时间线（`.fv-timeline-pane`）：默认目标高度占比 38%，分隔条可拖动或键盘调整到 26–65%，受 `min-height ≥ 300px` 约束；分区只改本地布局，不触发读取或渲染。lane 滚动仅发生在 `.fv-scroll` 内部。窄屏改为纵向堆叠，不显示分隔条。
- 常驻控制顺序：工程文件 → 监视器/帧步进 → 已选片段动作 → 全片导航/帧标尺/轨道。全片导航只平移/缩放显示窗口；分割/移除只加入待预检批次，不代替显式提交。
- 工程数据/协议诊断和时间线操作说明放入属性面板；独立时间线组件仍保留完整详情。选区工具栏在宽屏保持单行，紧凑轨道保留 46px lane / 40px clip，避免工具文字挤掉轨道。
- 次要入口（路径打开、验证边界、已有成片）一律默认折叠的 `<details>`；路径入口在顶栏，按需浮出表单，不永久占一行监视器高度。图片工具与生成控件共行，展开时才占纵向空间。

## 持久文字预算

- 常驻可见文案以中文短语为主（≤12 字/控件动词：生成 / 复制 / 入稿 / 取消 / 刷新）。
- 法律/边界整句（写入授权、来源未知声明）保留语义但收进折叠区或 `title` 提示；确权 checkbox 标签用短语（如「允许写 cache/preview（仅本次）」），完整句放 `title` 与详情内。
- 禁止中英混排遗留（如 "Query stored blocks"、"Frame (blank = all)"）；面向用户的动词用中文业务语，不用实现描述。

## 图标与交互

- 常用导航、缩放、选区、引用、预览与面板切换使用统一的 Lucide 线性 SVG，不保留「图标 + 重复动作文字」。工程名称、帧号、片段范围和文件名仍是可见信息；空态引导、配置保存、写许可、预检与提交保留明确文字，不把后果藏进图标。
- 固定 vendored `lucide-static` 1.70.0 子集，24×24 viewBox、2px 描边、18px 常用图标；只随客户端打包结构化 SVG 数据，不加载 CDN 或第二套 React。完整 ISC 和 Feather MIT 附录随源码和 ZIP 的 [第三方声明](THIRD-PARTY-NOTICES.md) 交付。
- 图标控件仍是原生 button / summary，提供完整 `aria-label`、视觉隐藏名称与禁用/切换状态。悬停或键盘聚焦显示可关闭的顶层提示；Escape 先关闭提示，不误关工作台。提示可悬停，滚动、失焦、隐藏页、属性变更与卸载回收监听和短暂离开计时器；不支持 Popover 时保留原生 title。

## 密度与层级

- 图标按钮 34×34px，粗指针 44×44px；工作台正文与查询提示不低于 12px。帧号等 meta 数字使用 `tabular-nums`。
- 单色调 + 一处强调色（`--fv-accent`）；层级靠 surface 亮度微阶与 1px 低对比描边，不加阴影堆叠。
- 时间线 ruler/lane 网格是本工作台的签名元素，保持低噪、帧号 `tabular-nums`。

## 状态与边界展示

- 拒绝类文案（未定帧、版本过期、未验证成片）必须出现，但只占一行 + role=alert/status，细节进 `<details>`。
- 「已有成片」入口默认折叠；内部保留 provenance UNKNOWN 声明，不将文件存在当成与当前版本对应的证据。
