## 一、产线总览（三步法，总控+子智能体分工）

1. **规格确认**：按下表 §二 定画布与安全区（比例结论有平台时效，**跨季度复用前抽查一次线上现况**）。
2. **文案**：从 02-script/PUBLISH-PACK 提炼，大标题+小字两行定稿（方法 §三）。
3. **背景+合成**：imgen 生成抽象画背景（§四/§五）→ `make_cover.py` 一条龙合成+预览+QC（§六/§七）→ 独立视觉子智能体 OCR 复检 → 人工终审。

## 二、显示规格与文字安全区（2026-09-13 调研实证）

| 项 | 结论 | 依据 |
|---|---|---|
| 上传比例 | **16:10**（官方建议下限 1146×717；推荐直接 **1920×1200**） | 官方口径+多信源交叉 |
| 电脑端（网页版全入口：首页/搜索/空间/动态/排行榜） | **16:9 容器居中裁上下各 5%** | 当日线上 CSS/CDN 实测（`--cover-radio:56.25%`、`!web-home-common-cover 672w_378h` 等） |
| 手机 App 首页/空间双列卡 | **≈1.38:1，裁左右各 ~7%** | 封面预览工具复刻值+社区共识 |
| 手机 m 站/动态/稍后再看 | ≈16:9（裁上下） | m 站 CSS 实测+类比 |
| 文字安全区（并集+UI 避让） | **水平 12%~88%、垂直 10%~80%**；右下 ~18%×13% 为时长角标禁区；排行榜左上 ~20%×12% 有排名角标（非榜单场景可忽略） | 裁切数学+UI 遮挡测量 |
| 主标题字高 | **≥ 画布高 8%**（1920×1200 下 ≥96px；缩略图 1 秒可读的实证线） | viyi 自查法（缩到 200×100 仍可读） |
| 上传格式/体积 | JPG/PNG，**≤2MB 最稳**（官方容忍 5MB、第三方多说 2MB，取严） | 两说并存取严 |

**排布经验**：主标题块垂直 27%~50%（视觉重心中间偏上）；小字块底 ≤62%（避右下角标+底部渐变条）；水平居中 ±38%。

## 三、文案方法（大标题 + 小字，仅此两行，不加其他元素）

- **大标题 ≤12 字**（6~10 字最佳）：信息流半宽缩略图上 1 秒读完；**与视频标题信息互补而非重复**——标题讲身份（我做了一个 X），封面讲卖点（X 好在哪），不浪费封面这个独立信息位。
- **小字 ≤14 字**：辅助说明，三选一方向——技术属性（开源/纯本地/平台名）／结果导向／仓库指引。**「开源」二字对 Linux受众是强筛选词，值得占位；GitHub URL 在小图上不可读，不放**（简介与置顶评论承担引流）。
- 不标题党、无「唯一/首个」类措辞（brief 风险词约束）；文案必须能在 02-script 找到口径锚点。
- voice-ime 案例：标题《我做了一个 Linux 语音输入法》→ 封面「**说话 就是 打字**」（U1 段「同一候选框接住两种输入」的口语化）+「**Linux 开源 · 语音键盘同引擎**」。

## 四、视觉与配色

- **基线=D22 铁律**：禁深蓝/蓝紫渐变科技风；暖色基线（卡其/琥珀）。
- **补色方案**：大面积**暖琥珀色域**背景 + **深藏蓝 `#1E3A63` 文字**（橙↔蓝互补；冷色只出现在文字与少量笔触，不构成「深蓝风」违例）。
- **背景=现代抽象画**：大面积纯色域 + 少量笔触质感（画刀/干笔肌理）；主题意象化为抽象元素（如语音=横贯的声波细线），**不用界面截图拼贴**。
- **排版形态**（make_cover.py 默认即此）：大标题按空格分段、**奇数段细体 55% 字号**（重-细-重节奏，如「说话/就是/打字」）；小字加宽字距 0.22em。
- 字体栈 `'Noto Sans CJK SC', '霞鹜新晰黑', sans-serif`；Black/900 档本机在位（fc-list 实证）。

## 五、背景生成（imgen，付费动作人工授权）

```bash
cd <video_tools>
# 模型选型：GPT 系（用户拍板 D50：封面生图限 GPT 系，不用 nano 兜底）
env python3 imgen/imgen_cli.py gen "<提示词>" --out <项目> \
    --model gpt-2.5-sunburst --quality high --ratio 2048x1280 --kind raw --yes
# 产物 <项目>/assets/imgen/<UTC>-<n>.png；task_id 记账在 <项目>/cache/reports/imgen_jobs_*.json
```

- **提示词原则**（沿 09-背景重制提示词 v2 的共创定调）：把模型当聪明人对话——只讲意图（要什么/为什么/想达成什么感受）；**否定式与机械约束不进 prompt**（「无文字无水印」这类下沉到 §七 QC 人选图把关）；艺术词汇具体（色相名+肌理名），场景感描述谨慎（软性场景词疑似触发审核）。
- **选型**：flare=快速档但**有审核误杀记录**；sunburst=慢速精修，本项目两次实证可用（背景重制+封面）；基础版 gpt-2.5 只出 1K 方图且比例串被忽略。
- **验收（生成后逐张过，再进合成）**：① 无文字/字母/水印 ② 大面积暖琥珀主导、非蓝紫/深色主导 ③ 中央偏上（文字落区）色域均匀 ④ 宽 ≥1920（比例不对交 prep-bg 裁切，见坑位②）。

## 六、合成与渲染（`scripts/make_cover.py`，零外部 Python 依赖）

```bash
# 一条龙（prep-bg → render → previews → qc）：
env python3 <video_tools>/scripts/make_cover.py all --out <项目>/cover \
    --bg-src <项目>/assets/imgen/<UTC>-<n>.png \
    --title "说话 就是 打字" --sub "Linux 开源 · 语音键盘同引擎"
# 分步：prep-bg <src> -o bg.png / render --out <dir> --bg bg.png --title … --sub … / previews --dir <dir> / qc --dir <dir>
```

**产物目录契约**（`<项目>/cover/`）：`bg_1920x1200.png`（lanczos cover-crop 精确画布）／`cover.html`+`cover.meta.json`（渲染源+参数自述，qc 据此复检）／`cover_1920x1200.png|.jpg`（母带+上传版，JPG 自适应 ≤2MB）／`previews/{pc_16x9,thumb_384,app_138,app_43}.png`（1920×1080/384×216/1656×1200/1600×1200）／`cover_qc.json`（验证门报告）。

**定稿默认参数**（=voice-ime 实测验收值，全部可用 CLI 覆盖）：画布 1920×1200；标题 top=325/size=205/weight=900，细体段 55%/300，段距 28px；小字 top=659/size=46/weight=500/字距 0.22em/不透明度 0.85；文字色 #1E3A63；这些值已满足 §二 安全区（改参数=改配方，须拍板并复跑 qc 几何守卫）。

## 七、QC 门（两级）

**脚本自动门（`qc` 子命令，FAIL 退出码 1）**：① cover/bg/四预览 ffprobe 尺寸断言 ② 安全区几何守卫（标题块与小字块底界、标题估算宽度、8% 字高下限）③ 标题区背景 YAVG ≥115（signalstats，深底预警）④ JPG ≤2MB。
**人工+视觉门**：缩略图（thumb_384）大标题 1 秒可读；独立视觉子智能体四图 OCR 复检（无裁字/无水印/对比度/构图拥挤感）——**视觉读图只作线索，几何与尺寸以像素/ffprobe 证据为准**；用户人眼终审。投稿时网页创作中心的裁切预览框再自查一次。

## 八、已知坑位（2026-09-13 实测）

1. **速创 flare 端点审核误杀**：无害纯抽象画中文提示词两连 status=3 拒绝（不退款、排队数分钟后转拒）——重要生成直接用 sunburst，勿把 flare 当唯一依赖（已入册 imgen/README「已验证版本」）。
2. **sunburst 忽略 aspectRatio**：payload 携带 `2048x1280` 仍出 1K 方图（1024²）→ 由 `prep-bg` cover-crop 到 1920×1200，**1.875× lanczos 放大**（脚本自动警告倍数；抽象平涂色域可接受，精细纹理需重生成）。
3. **4:3 预览尺寸口径**：4:3 of 高 1200 = **1600×1200**（裁左右各 8.3%）；曾误算 1440（6:5）——1600 才是真 4:3，脚本已按比例通用计算。
4. 小字在缩略图（384px）上不可读属平台常态，不按缺陷处理；大标题承担信息流触达。
5. Chrome headless 截图确定性良好：同 HTML+字体+背景多次渲染**字节一致**（§九），可放心把 make_cover.py 当幂等重铺工具。
6. 上传体积取 ≤2MB（官方容忍 5MB 的说法不可考，help.bilibili.com 已无解析）。
