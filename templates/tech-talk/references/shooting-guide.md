## 一、相机参数（M43 口播定稿，D23/D24）

| 项 | 定稿值 | 依据 |
|---|---|---|
| 分辨率/帧率 | **4K 30p**（29.97 与 30fps 管线无感兼容） | 头部科技 UP 实测 8/8 为 30fps 系；4K→1080p 超采样更锐+punch-in 裁切余量+慢快门换低 ISO；60fps 在 30fps 管线无用途 |
| 快门 | **1/60s** | 30p 的 180° 快门；50Hz 市电防频闪 |
| 光圈/ISO | f/2.8-4（f/4 优先）/ **≤800 目标（400 更佳）** | 镜头锐度区间；M43 高感短板，打灯到位后可达 |
| 白平衡 | 手动锁定（按主灯色温） | 禁自动防漂移 |
| 焦段 | **36mm 等效** | talking head 主流 35-50mm；广角端不拍近脸（透视变形）留作 B-roll |
| 构图 | 眼睛上三分之一线、胸下入画、1.2-1.5m 距离 | 行业标准口播构图 |
| 照片风格 | 标准/自然，锐化对比 −1 档 | 留给后期 |
| 倒置拍摄 | 允许，入库时 `hflip,vflip` 转正 | 已验证无损 |

## 二、机位与提词

- **相机悬于显示器正上方中央**：显示器顶部高度 ≈眼高 → 俯角近零、桌面手势入画、**提词位与镜头同轴**（视线不飘）。
- 提词：手机/平板贴镜头正下方，黑底白字；**录制时显示器只显示黑底提词稿**（消屏幕杂光、稳白平衡）。
- 架设选型三查（项目实例：SmallRig 蟹钳夹+魔术臂+迷你球台）：承重 ≥1.5kg / 1/4" 螺口 / 臂长 ≥30cm。
- 防震：架位与手隔离、垫毛巾；录口播双手放腿上；手机 App 遥控开关录。

## 三、打光三原则与灯位几何

- **三原则**：①关宿舍顶灯（单顶光=眼窝/下巴阴影）②全屋单一色温 5000-5600K（杂灯全关）③柔光=光源相对脸的面积（小灯拉近 30-60cm+柔光件胜过大灯远打）。
- **几何约束**：36mm 等效横 FOV≈53°（半角 26.6°）→ 画面半宽=0.5×纵深。取景走廊内的立杆/经典 45° 近距灯位**必然穿帮**——可行灯位只有三类：
  - **A 主推：另一台显示器上沿**（与相机分属两台显示器=震动隔离；高位近轴顺光、阴影浅、自带眼神光、抠像最友好；戴眼镜灯挂高，反光落点低于镜头）；
  - B 立体感：椅侧大三脚架，横向偏离光轴 ≥1.0m、灯头 1.5-1.7m；
  - C 最柔：天花板反弹（损 2 档需全功率）。
- 进深浅选灯逻辑：**买大不买小**——大功率低亮度运行=温控风扇基本不转（录音友好）+续航翻倍（项目实例：Ulanzi C01 100W 主推 / PL25 省钱档）。
- 曝光验收线：ISO 400-800 / f/2.8-4 / 1/60。开录前 LED 频闪检查（1/60 与 1/1000 各录 2s 查滚动条纹）。
- 人离墙 ≥80cm；主光偏正面=人物亮于背景，对抠像友好。

## 四、录音（双系统）与底噪

- **管线红利**：vtx 契约 voice 独立于 A-roll 画面轨 → 同期声与分轨补录（ADR）两条路都通。
- **推荐路径按序试**：①同期声头顶 boom（电容麦吊口前上方 30-40cm，高于画框顶即不入画；心形对嘴、null 朝机箱）②吸音增强（相机身后/两侧永不入画：挂毛毯堆被子；GPU 空闲、机箱风扇 0dB）③分轨 ADR 保底（现场只留参考音，桌面近距补录，逐窗 20-40s 漂移不累积）。
- **桌面电容麦不可用**于 1.3-1.5m 机位（80cm 已掉 10dB 信噪，外推 ≈−15dB）；相机内录麦的「响」是 AGC 假象（LRA 抽泵不可还原），只配当同步参考音。
- 底噪先查电气再上算法：50Hz 工频哼声稳定 ±0.1dB=电气签名，「手摸麦壳变安静」=Pin 1 屏蔽悬空（换 XLR 线/补 AES48 搭接可根治）。
- 降噪生产链与已验证适用域见 [denoise 插件](../../../plugins/denoise/README.md)。项目选型对照记录：MossFormer2=远距事故鲁棒冠军；DFN3 人声埋深时灾难失败慎用；ASR 回测可懂度无损。项目天花板评估：残余 50dB 信噪已低于交付链路可闻域，过度处理有音色塑形风险。

## 五、双系统同步录制纪律（D26）

- **三条纪律**：①相机内录麦保持开启（=同步参考轨）②声卡录制中途不中断 ③段间留 1-2s 气口（切段定位用）。
- **长镜模式**（用户习惯拍板）：一次性连续长录避免停机重启改变语感；工作量移到后期（conform→静音/ASR 首句切段→对窗体检）；逐窗独立对齐，漂移永不跨段累积；超窗段当场补录单段插入。
- LTC 时间码否决：帧级分辨率（33ms）反而低于相关法（亚毫秒），单机位纯冗余。
- 同步工具与残差分级 → `aroll-pipeline.md` §3；**录完先跑 sync 工具再进管线**。

## 六、背景合成透视一致（抠像支线拍摄端）

- 问题：AI 背景图与实拍人物透视不匹配（灭点/视平线/景深），大脑判定「人不在那个房间」。
- 主路线（项目实例拍板）：GPT Image 参考帧两步法——「保持视角/透视/光源/色调不变替换背景」→「移除人物补全」；依据=指令式多模态对参考图改写的结构保持优于 depth-ControlNet。
- **拍摄端锁参（双向另一半）**：背景生成后，相机高度/焦段/俯仰每次按同摆位——背景与拍摄参数互锁。
- 选图硬规则：视平线中上部（匹配眼高机位）；回避强透视线或已虚化；景深匹配（轻度自然虚化，AI 输出偏软与虚化策略合流）；生成指令显式指定光源方位=实拍主光方向。
- 抠像工作流定档：转正 → 抠像@2048（4K 原生 OOM，2048 对 1080p 成片精度充裕）→ guided filter 收边 → 背景合成 1080p（项目实例：BiRefNet_HR@2048+MatAnyone2 开源链黑点根因=肩缘错分类 → 达芬奇 Magic Mask matte 现行权威，D49）。
- 金属框眼镜绿幕镜片透色 → 倾向纯色墙/清理版背景。
