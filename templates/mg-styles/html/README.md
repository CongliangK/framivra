# 15 种可换题材的 HTML 参考

打开 [index.html](index.html) 后选择一款。各款页面位于 `../styles/<风格>/assets/html/`，直接加载同目录的独立场景脚本，并共用本目录播放器与 CSS，不依赖 Python 生成器、网络字体或打包工具。播放器以 30fps 选择整数帧，拖动、前后帧和内容编辑共用同一个帧函数；两个题材的数据与该风格的短制作卡就在场景源码中。

更换题材时先改对象的含义、因果或任务，再调时间窗，最后调配色。阅读制作卡的适用范围、视觉隐喻、分镜、不可删特征、可替语义、动作/转场/声音点、失败反例和具体编辑练习。声音点是编排建议，本批 HTML 没有音轨。

捕获方先等待 `window.MG_REFERENCE_READY`，再等待 `window.__vtx_render(frame)`；`frame` 必须是有效整数。`window.__vtx_export_png()` 读取当前画面。`?capture=1` 隐藏控制与说明，`?f=42` 同时指定初始帧。浏览器字体就绪后才绘制；文本框有最小字号、行数和高度，放不下时应缩短文案或修改构图。

这些文件是设计参考。柔软 3D 是 Canvas 投影和构图示意，不能替代连续材质互动、变形和摄像机运动的 Blender 路线；液态是隐式场近似；玻璃是光学示意；字幕是事件与安全区布局示意。系统字体不随仓库打包。冻结研究环境的浏览器启动受阻，Node 测试只证明输入检查、整数帧命令流和控制逻辑，不能证明浏览器像素、字体观感或完整播放通过。媒体路线及实际渲染证据见 [上级 README 的验收边界](../README.md#验收边界)。
