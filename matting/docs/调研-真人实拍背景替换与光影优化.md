# 调研：真人实拍视频的 AI 背景替换与光影优化（2026-08-23）

> 场景约束：固定机位、单人室内 talking head、无绿幕、无棚灯、1080p、数分钟口播 A-roll；本地 RTX 4080 16G + ComfyUI；已有 vtx 剪辑管线（ProRes 4444 / PNG alpha 序列链路已验证）。
> 对应 AGENTS.md：D3（无棚拍条件）、D4（背景 AI 处理）、T1（背景技术路线未拍板）。本文为实证前调研，T1 拍板依据。

## 〇、总结论

### 背景替换：✅ 完全可行，且是成熟路线

- **首选：MatAnyone 2（首帧 mask 引导视频 matting）→ alpha 序列/ProRes 4444 → vtx 合成虚拟背景**。CVPR 2026 Highlight，当前公开 SOTA，专为时间稳定性设计；35M 参数 CNN，1080p 在 4080 上毫无压力（12G 消费卡即可跑，4K 会 OOM——本项目锁 1080p 正好）。有 HF 一行式推理 + CLI，无官方 ComfyUI 节点（v1 有），走外部脚本进管线更贴合 vtx 架构。
- **保底/对照：剪映专业版「智能抠像」**（免费，已达"发丝级可用"，内置边缘羽化+色彩匹配）。中文口播博主的无绿幕换背景已是 mainstream 做法。建议同一段素材两版人眼 PK 后定产线。
- **首帧 mask 生成：BiRefNet**（MIT 许可，2048² 高分辨率分割）跑一帧或手工精修一帧发丝，记忆传播全程保持。
- **MiniMax H3 整段重绘**：维持原定位，只给个别重点镜头用，不作背景替换主力。

主要风险与对策：
| 风险 | 对策 |
|---|---|
| 发丝"分割感"边界 | MatAnyone 2 相比 v1 边界指标降 22-27%；仍不满则手工精修首帧 mask |
| 眼镜/透明物半透明区闪烁 | 口播动作幅度小，抽查逐帧 alpha；必要时局部降羽化 |
| 快速挥手边缘抖动 | 避免穿与背景同色的长袖 |
| 许可证 | RVM 是 GPL-3.0、RMBG 是 CC-BY-NC（非商用），产线避免依赖；BiRefNet/BEN2/MIT 干净，MatAnyone 系论文开源 |

### 合成环节要点（决定"假不假"的关键）

1. 背景图按**原片光照条件**生成/挑选（提示词写"正面柔光、无强阴影、中性色温"）——比后期校正前景光照省事得多，可用现有 Z-Image/Slime 链路。
2. alpha 边缘 0.5-1px 轻羽化；见原背景色 fringe 则 mask 收缩 1-2px；发丝区羽化 3-8px。背景图用 PNG 不用 JPEG。
3. 色温匹配 + 接触阴影（20-30% 软投影，否则人物会"飘"）+ 朝背景光源一侧的轻 rim light。
4. 差异大时救场：**IC-Light fbc 模型**（前景+背景→光照统一合成）；更物理正确的路线是 **NVIDIA Maxine VFX Video Relighting**（人像+matte+HDRI 打光，4080 原生支持）。
5. 替代路线：**Video Depth Anything** 深度虚化原背景（不走抠像，风险更低），但背景"杂乱"只能减弱不能消除。

### 光影优化：⚠️ AI 能力边界明确，主推"一盏灯 + 调色"

- **业界共识：一盏高 CRI 补光灯胜过一切后期**。低 CRI 灯/混色温造成的坏肤色后期不可逆。典型配置 Godox SL60IID/Neewer GL25B + 柔光箱 ≈ ¥800-1800，固定机位一次布光终身复用。
- **AI relight 现状**：IC-Light v1 有肤色漂移/纹理改变问题（需 DetailTransfer+color match 补救链）；IC-Light v2（Flux 底座）细节保留大幅提升但**非商业许可**，且本质单图模型，逐帧用于视频会闪烁。学术前沿（Lux Post Facto CVPR2025、RelightVid、RelightVGG）质量好但无消费级落地。**结论：整段视频 relight 当前无可量产本地方案，不建议投入；IC-Light 只用于单帧封面/截图。**
- **后期标准链路**：Resolve 免费版一级调色（白平衡+肤色轮+轻对比，固定机位一条 grade 全片复制；可程序化为 ffmpeg/vtx 统一 LUT）→ 必要时 temporal denoise（对固定机位极有效）。肤色问题 90% 是白平衡+曝光问题。
- **画质增强：基本不值得做**。1080p 原生 + B 站 1080p 分发，上采样无收益；Real-ESRGAN 逐帧有时序闪烁硬伤；Topaz Video AI 2025-10 起 $299/年订阅（Adobe 收购前景不明）。唯一值得的"增强"是暗光降噪（Resolve temporal denoise 离线 / NVIDIA Broadcast 实时录制）。
- AI 美颜（GFPGAN/CodeFormer）逐帧稳定性差且"重画脸"，对真人质感是负资产，不采用。

## 一、人像分割/抠像模型对比

| 模型 | 类型 | 发丝 | 时间稳定性 | 许可证 | 状态 |
|---|---|---|---|---|---|
| **MatAnyone 2** | 视频 matting，首帧 mask 引导 | 优（边界 Grad/Conn 较 v1 降 27%/22%） | 最优（dtSSD 全基准第一） | 论文开源（NOASSERTION） | CVPR 2026 Highlight，~820 star，活跃；HF 一行式推理+CLI（2026-03） |
| MatAnyone | 同上 | 良（偏分割感） | 优 | 同上 | CVPR 2025，1.6k star，**有成熟 ComfyUI 节点**（KytraScript/ComfyUI_MatAnyone_Kytra） |
| RVM | 循环记忆视频 matting | 中（发丝软） | 优 | **GPL-3.0** | 9.5k star，停更；速度标杆（3090 1080p 172FPS，5 分钟视频<1 分钟）——适合管线内草稿预览 |
| BiRefNet | 高分辨率图像分割 | 优（2048²） | 无（逐帧） | MIT | 4.1k star 活跃；**定位：首帧 mask 生成器** |
| BEN2 | 图像 matting（CGM 精修） | 优（4K 发丝） | 无 | MIT | 逐帧会闪，不作整段 |
| RMBG-1.4/2.0 | 图像分割 | 良 | 无 | **CC-BY-NC** | 企业向，产线避免 |
| SAM2 逐帧追踪 | 通用分割 | 差（硬 mask 无 alpha） | 良 | Apache-2.0 | 选区工具，直接换背景有硬边 |
| ViTMatte | trimap matting | 优 | 无 | — | 可与 BiRefNet 级联精修单帧 |

MatAnyone 2 关键改进：学习式 Matting Quality Evaluator + 双分支标注构建 VMReal 数据集（28K clips/2.4M 帧）+ 参考帧策略（解决 v1 长视频人物外观变化跑飞的弱点）。真实基准 CRGNN：MAD 5.76→4.24、dtSSD 5.44→4.54。
注意：MatAnyone issue #50——**4K 原生分辨率 OOM（80G 卡也炸）**，1080p 安全；社区实测 3060 12GB 可跑。

## 三、光影/画质工具评估明细

- IC-Light v1（SD1.5，可商用权重）：relight 改变纹理、肤色漂移；补救链 = DetailTransfer + 高频分离 + color match（kijai ComfyUI-IC-Light 有保色 workflow）。
- IC-Light v2 / V2-Vary（Flux 底座，2024-10~11 放出）：细节保留远超 v1，Vary 专治低光/硬阴影；**非商业许可**；逐帧视频闪烁未解决。
- Lux Post Facto（CVPR 2025，Adobe/Debevec）：学术最强 portrait 视频重打光（两阶段 delight→relight 视频扩散），无可用代码/权重。
- RelightVid / SynthLight / RelightVGG（均 CVPR 2025 前后）：论文好，无消费级落地或复现难。
- Topaz Video AI：效果最好但 2025-10 起取消永久许可改 $299/年；Adobe 2026-06 宣布收购。
- Real-ESRGAN：免费，静态机位 talking head 是其最可用场景，但纹理呼吸/游移闪烁是硬伤；1080p 分发下无上采样收益。
- NVIDIA Broadcast（RTX 免费）：视频降噪对实时摄像头好评，适合直播/录制链路；离线文件首选 Resolve temporal denoise。
- GFPGAN/CodeFormer：逐帧时间稳定性差 + 倾向重画脸，**不用于口播视频**。

## 四、建议的落地管线（待 T1 拍板）

1. 拍摄前置：一盏高 CRI 补光灯+柔光箱（¥800-1800，一次投入）；衣物与背景色差拉大。
2. 背景替换：BiRefNet 出首帧 mask（或剪映导出）→ MatAnyone 2 全片 alpha（1080p）→ ProRes 4444/PNG 序列 → vtx overlay 虚拟背景（Z-Image 按原片光照提示词生成）→ 边缘羽化+色温对齐+接触阴影。
3. 光影：Resolve/ffmpeg 固定 grade（白平衡→提亮阴影→肤色轮）+ 按需 temporal denoise；不做 AI 整段 relight、不上采样。
4. 验收：同段素材剪映版 vs 本地管线版人眼 PK；MatAnyone v1 ComfyUI 节点可先快速试水再等 v2 节点/CLI。
