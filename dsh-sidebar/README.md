# 在 DSH 中制作视频

查看时间线、按整数帧或「秒 + 零基帧偏移」定位，把画面与引用加入对话草稿；剪辑先预检，再确认保存。

**首次使用：** 在下方扫描或安装内核 → 保存配置 → 检查连接。然后回到会话，打开右侧 **Framivra** 并选择时间线。

- **内核**：扫描已有安装，或从可信的本地 Framivra wheel 安装到独立环境，不覆盖系统 Python。
- **配置文件**：常用字段表单与完整 JSON 编辑；全局缓存三选一：`off` 不读取或保留可复用缓存（临时件用后清理）、`core` 压缩保留高价值 gfx、合成缓存短暂（缺省/推荐）、`aggressive` 保留更多缓存。缺失字段只显示推荐值，不自动写回；确认保存会影响使用同一 `VTX_CONFIG` 的所有工程，下次操作读取生效，不改变运行中任务、不立即清理旧目录。保存前比较内容，保留备份并检查冲突。
- **工程配置**：时间线的「属性与编辑」中查看固定帧率/画布，调整时长、图形依赖及素材/音轨插件参数；授权后加入批次、预检，再确认保存。根级插件只读；插件安装与真实效果不由结构计划证明，预览仍限已保存、已准备的纯内核工程。
- **检查**：核对连接与预览、编辑能力。结构检查不等于完整渲染测试，FFmpeg、浏览器与模型需另行准备。

缺少图形缓存时，勾选「允许按需准备当前帧图形」，可见 HTML 还需单独确认信任已保存页面/脚本，再显式生成完整合成帧。普通媒体、透明图形和字幕仍按内核顺序合成，不是单页截图；只准备请求帧，不要求先跑整页或完整成片。HTML 不是沙箱，仅用于检查过的可信工程。PNG 无音频，不能替代完整 `all` 与音频/QC。

扫描不执行程序；安装与保存需明确确认。预览许可、冷准备与 HTML 信任和剪辑授权分开；排队包含在原 30 秒预算内，可显式取消，不自动重试。冷准备临时文件在响应前清理，图片与引用仍须再次点击才进入草稿，不发送。

适配 **DSH 0.2.2-rc.1 / Node ≥24.9.0**。[开发与验证记录](https://github.com/CongliangK/framivra/blob/main/dsh-sidebar/DEVELOPMENT.md) · [反馈问题](https://github.com/CongliangK/framivra/issues)
